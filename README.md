## 🚀 Инструкция по запуску

### 1. Установка всех компонентов
После клонирования репозитория разверните зависимости:
```bash
npm install
```

### 2. Режим разработки (Исходный код)
Для запуска локального сервера с автообновлением (Pug, SCSS, TS):
```bash
npm run dev
```
Проект откроется на `http://localhost:3000`

### 3. Сборка и локальная проверка деплой-версии (Production)

1. **Сборка проекта:** Для компиляции, оптимизации и сжатия кода в финальные файлы запустите команду:
   ```bash
   npm run build
   ```
   После этого в корне проекта сгенерируется изолированная папка `dist/`.

2. **Запуск и тестирование:** Для локального запуска готовой production-версии выполните:
   ```bash
   npm run deploy
   ```
   Программа поднимет сервер деплоя, и готовый оптимизированный сайт с анимациями GSAP будет доступен по адресу: ` http://192.168.0.3:5000`

### 🛠️ Дополнительно
* **Адаптивность:** Помимо десктопной версии по ТЗ, проект адаптирован под планшетные экраны (брейкпоинт `$tablet: 1280px`). Меню хедера скрывается, а контентные блоки благодаря **Flexbox** подстраиваются под ширину экрана.
